📝 KEY CHANGES EXPLAINED
═════════════════════════════════════════════════════════════════

Configuration Change:

  OLD (docker-compose.yml):
  ──────────────────────
  volumes:
    postgres_data:

  NEW (docker-compose.yml):
  ──────────────────────
  volumes:
    postgres_data:
      driver: local
      driver_opts:
        type: none
        o: bind
        device: ${PWD}/data/postgres

Benefits:
  • driver: local         → Use local storage driver
  • type: none           → Bind mount to local directory
  • o: bind              → Bind mount options
  • device: path         → Where data is actually stored

💡 TIPS & TRICKS
═════════════════════════════════════════════════════════════════

Backup Database:
  docker exec app-db pg_dump -U postgres onlineshop > backup.sql

Restore Database:
  docker exec -i app-db psql -U postgres onlineshop < backup.sql

Backup Volume:
  tar -czf backup.tar.gz ./data/postgres

Check Volume Details:
  docker volume inspect postgres_data

Monitor Disk Usage:
  docker system df

Clean Everything (be careful!):
  docker system prune -a --volumes -f
