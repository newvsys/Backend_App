│ 💾 BACKUP STRATEGY                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

Database Backup:
  docker exec app-db pg_dump -U postgres onlineshop > backup.sql

Volume Directory Backup:
  Windows: Compress-Archive -Path ./data/postgres -DestinationPath backup.zip
  Linux: tar -czf backup.tar.gz ./data/postgres

Restoration:
  Database: docker exec -i app-db psql -U postgres onlineshop < backup.sql
  Volume: Extract backup to ./data/postgres

Schedule: Weekly automatic backups recommended
